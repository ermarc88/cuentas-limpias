Política de privacidad

Plataforma Cuentas Limpias · Última actualización: 17 de noviembre de 2026

InicioEnglish

Esta aplicación usa los Servicios de API de YouTube. Al usarla aceptas los Términos de servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de privacidad de Google.

Quién la usa

La Plataforma Cuentas Limpias es una herramienta privada de los propietarios del canal de YouTube «Cuentas Limpias». Se ejecuta en sus propios ordenadores y no está abierta al público.

Qué datos de Google usa y para qué

  • Permiso para subir vídeos (youtube.upload): subir al canal conectado los vídeos que el propio usuario elige, con el título, la descripción y la fecha de publicación que él indica.
  • Lectura básica del canal (youtube.readonly): obtener el nombre y el identificador del canal conectado para mostrar a qué canal se va a subir.
  • Si en el futuro se añade la analítica del canal (yt-analytics.readonly), sus métricas se usarán solo para mostrar al propietario el rendimiento de sus propios vídeos.

La aplicación no accede a datos de otros usuarios, ni a comentarios, mensajes, contactos o información de pago.

Dónde se guardan

Los permisos de acceso (tokens OAuth), el identificador y el nombre del canal y el registro de las subidas se guardan solo en el ordenador del propietario, en una base de datos local. No hay servidores propios en internet ni copias en la nube.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad. La aplicación solo se comunica con Google/YouTube para realizar las acciones que el usuario pide.

Cómo retirar el acceso y borrar los datos

  • Desde la plataforma: botón «Desconectar», que revoca el permiso en Google y borra el token local.
  • Desde tu cuenta de Google, en cualquier momento: página de permisos de seguridad de Google.
  • Al desconectar, el token se borra en el momento. El registro local de subidas puede borrarse a petición o eliminando la base de datos local. Ningún dato de la API se conserva más de 30 días sin volver a actualizarse.

English

This application uses the YouTube API Services. By using it you agree to the YouTube Terms of Service; Google's handling of data is governed by the Google Privacy Policy.

  • Who uses it: only the owners of the «Cuentas Limpias» YouTube channel, on their own computers. It is not public.
  • Data accessed: youtube.upload to upload the videos the user selects to their own channel (with the title, description and publish time the user sets); youtube.readonly to read the connected channel's name and ID. Optional future analytics (yt-analytics.readonly) would only show the owner their own channel's metrics.
  • Storage: OAuth tokens, channel name/ID and the upload log are stored only locally on the owner's computer. No cloud servers.
  • Sharing: none. Data is never sold, shared with third parties or used for advertising.
  • Revoking access and deletion: use «Desconectar» in the app (revokes the token at Google and deletes it locally) or Google security settings. Tokens are deleted immediately on disconnect; API data is not kept for more than 30 days without being refreshed.
